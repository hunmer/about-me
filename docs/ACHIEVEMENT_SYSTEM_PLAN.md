# 成就系统清单 V3（多级制 · 达成条件 · 生图批次）

> 更新日期：2026-10-08（V3：补达成条件列 + 图标编号 A01~A74 + 生图批次表）
> 数据来源：`lib/plugins/` 26 个插件的既有数据与事件总线
> 联动机制：`EventManager` 事件 / JS API 计数 → 达标升級 → `store.controller.addPoints()` 发放积分

## 设计原则

1. **多级制**：每个成就为一个系列，含 3~5 个等级（Lv1~Lv5），数值按 ~10 倍级递增。
2. **图标共用主体**：同一成就各级共用一个图标主体，等级用**边框/底色**区分：Lv1 灰铁 / Lv2 青铜 / Lv3 白银 / Lv4 黄金 / Lv5 彩虹流光。
3. **生图风格**（参照 `original-52b79381e4caafd86dcd4021cc1f96f9.jpg`）：扁平卡通贴纸风、**六边形徽章**、白色粗描边、柔和渐变底、明亮配色、无文字。
4. **积分奖励**：按等级位次 Lv1=50 / Lv2=100 / Lv3=300 / Lv4=800 / Lv5=2000（不足 5 级取前 N 档），进 `pointAwardSettings` 可调。
5. 需补埋点的条目在条件列以【】标注；隐藏成就以【隐藏】标注。
