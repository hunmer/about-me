📋 使用说明

这是一个独立的测试页面，用于开发和测试 Aboutme 的 JavaScript API。你可以在控制台中直接调用这些方法：

// 基本用法示例
Aboutme.ready(() => {
  console.log('Aboutme is ready!');
});

Aboutme.system.getCurrentTime().then(time => console.log(time));
Aboutme.ui.toast('Hello from Aboutme!');
Aboutme.storage.write('test', { message: 'Hello' });
Aboutme.storage.read('test').then(data => console.log(data));
