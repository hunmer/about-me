# admin-vue 页面说明

Aboutme Sync Server 的管理面板，单页应用（无路由）。未登录时显示登录/注册表单，登录后通过顶部 Tab 切换 6 个页面。

## 全局布局

### AppHeader（顶栏）
- 展示：应用标题 "Aboutme Sync Server"、服务器状态标签（在线/离线）、当前用户名
- 功能：退出登录（带确认弹窗）；服务器状态每 30 秒自动检测一次

### TabNavigation（导航栏）
- 展示：6 个 Tab 入口 —— 概览 / 文件管理 / API Keys / 插件商店 / 设备管理 / 设置

---

## 登录页（LoginForm）

- 展示：用户名、密码、服务器地址三个输入项；默认凭据提示（admin / admin123）
- 功能：
  - 登录成功后加载文件列表、API Keys 并检测服务器健康状态
  - 支持注册成功后返回时自动预填充用户名密码
  - 切换到注册页

## 注册页（RegisterForm）

- 展示：用户名、密码、确认密码、服务器地址输入项
- 功能：
  - 校验用户名 ≥3 字符、密码 ≥6 字符、两次密码一致
  - 加载时检查服务器是否开放注册，关闭时显示提示并禁用表单
  - 注册成功后切回登录页并预填充凭据

---

## 概览页（OverviewTab）

- 展示：
  - 统计卡片 ×4：用户名（含注册日期）、同步文件数（含文件夹数）、总存储大小（MB 及格式化大小）、服务器状态（在线/离线 + API 是否启用）
  - 最近活动列表：活动图标 + 消息 + 时间（来自各页面操作记录，如下载/删除/创建 Key）
- 功能：点击"服务器状态"卡片跳转到设置页

## 文件管理页（FilesTab）

- 展示：
  - 文件树（懒加载展开子目录），文件显示大小、更新时间，文件夹显示子项数
  - 批量操作栏：已选文件数量提示
- 功能：
  - 单文件：下载（解密后下载，二进制直接下载、文本保存为 JSON）、删除（确认弹窗）
  - 批量：勾选文件/文件夹（选文件夹自动递归选中其下所有文件）后，批量下载（打包 ZIP）或批量删除
  - 刷新文件列表

## API Keys 页（ApiKeysTab）

- 展示：
  - 说明提示（Key 用于 MCP Server 等外部应用，只显示一次）
  - Key 列表：名称、前缀、过期时间（或永不过期）、最后使用时间、已过期标签
- 功能：
  - 创建 API Key（弹窗填写名称 + 过期时间：永不过期/7天/30天/90天/1年）
  - 创建成功后结果弹窗：展示完整 Key、复制按钮、MCP Server 配置示例
  - 撤销 Key

## 插件商店页（PluginsTab）

- 子 Tab「已安装」：
  - 展示：插件数量、插件卡片（标题、状态标签 已启用/已禁用/已安装、作者、描述、版本、官网链接）
  - 功能：启用 / 禁用 / 卸载（确认弹窗）；上传本地 ZIP 插件包；配置商店入口
- 子 Tab「插件商店」：
  - 展示：商店插件列表（标题、作者、描述、版本），已安装的显示"已安装"
  - 功能：从商店一键安装、刷新商店列表；未配置商店 URL 时引导配置
- 商店配置弹窗：填写商店 JSON URL（服务器定期从该地址拉取插件列表）

## 设备管理页（DevicesTab）

- 展示：已登录设备列表，按平台显示图标（手机/桌面/笔记本/平板），含设备名、平台标签、device_id、注册时间、最后同步时间、FCM token
- 功能：
  - 推送消息：可推送到单个设备或所有设备（弹窗填写标题 + 内容）
  - 删除设备（确认弹窗，删除后该设备需重新登录）
  - 刷新设备列表

## 设置页（SettingsTab）

由两个卡片组成：

### API 访问控制（ApiControl）
- 展示：
  - API 访问开关（控制是否允许通过 API 访问数据）
  - 加密密钥状态（已设置/未设置）；已设置时展示当前密钥并可复制
- 功能：
  - 设置加密密钥：输入 Base64 密钥（44 字符），通过解密服务端验证文件校验正确性后保存到本地
  - 清除本地密钥（确认弹窗）
  - 提示：密钥可在 Aboutme 客户端"设置 > 开发者选项"查看

### 数据操作（DataOperations）
- 展示：破坏性操作警告提示
- 功能：
  - 导出数据：服务端打包为 ZIP 后下载，完成后提示文件数与大小
  - 清空服务器数据（二次确认，删除全部同步文件，不可恢复）
