# 对外接口

> 所属：packages/api_forwarding_server · [返回索引](../CLAUDE.md)

## WebSocket 端点

- 地址：`ws://<host>:8654`（前端与客户端同端点连接）。

## 协议要点

| 机制 | 说明 |
|------|------|
| 配对 | 前端与客户端在连接时携带**相同的配对密钥**（形如 `ABCD-1234-EFGH-5678`），服务器将两条连接绑定为会话（`session.ts`） |
| 转发 | 前端请求 → 会话内路由至客户端 → 客户端经 JSBridge 调插件 API → 响应按原路径回前端 |
| 心跳 | 周期心跳检测连接活性，超时清理会话 |

- 消息字段与类型以 `src/types.ts` 及 `README.md`"消息协议"章节为准（本次扫描未逐字段抄录）。
